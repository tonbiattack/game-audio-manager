# GUI スタートアップ ショートカット設計

## 意図

ログオン後に Game Audio Manager をすぐ操作できるよう、現在の Windows ユーザーのスタートアップ フォルダーから GUI を起動できるようにする。

## 目標

- `game-audio-manager.ps1` を起動する `.lnk` をユーザーごとの Startup フォルダーへ登録する。
- 同じスクリプトの `-Remove` で、そのショートカットだけを削除できる。
- 実行元を固定せず、スクリプト自身の配置先から GUI の絶対パスを導出する。

## 非目標

- 全ユーザー向けの登録、管理者権限、タスク スケジューラの利用。
- 既存の出力先監視スクリプトの常駐設定の変更。

## 選択肢

1. 手動で Startup にショートカットを作る: 実装不要だが、毎回パスと引数を入力する必要がある。
2. タスク スケジューラへ登録する: 細かい制御はできるが、GUI を開くだけには過剰で設定画面も分かれる。
3. PowerShell で `.lnk` を登録する: Windows の標準 Startup と親和性が高く、登録と解除を一つのコマンドで完結できる。

選択肢 3 を採用する。`WScript.Shell` COM を使い、リンクの対象は `powershell.exe`、引数は `game-audio-manager.ps1` の絶対パスとする。GUI のためウィンドウは非表示にしない。

## 検証

- ショートカット定義が正しいパス・引数・作業ディレクトリを返すことを自動テストする。
- 一時フォルダーを Startup として登録・削除し、`.lnk` の作成と削除をテストする。
- 実際の Startup フォルダーへの登録は、マージ済み main で一度だけ行う。
